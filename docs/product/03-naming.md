# Naming and voice — Phase 7

| Candidate | Meaning / strength | Concern |
|---|---|---|
| Soglia | A threshold, an invitation into a home; short Italian word | Common word, possible existing marks; international pronunciation |
| Accasa | Direction toward home, friendly sound | Resembles “a casa”; crowded housing associations likely |
| Dimora | Familiar residential meaning | Very broad and widely used |

**Soglia** is selected as a replaceable working name for local product design. No trademark, business-name or domain availability search/clearance has been completed. Do not register, publish or claim exclusivity. Central brand configuration must make replacement inexpensive. Repository identity remains LinkedHome.

Voice: calm, concrete Italian. Use “preferenze compatibili”, “invito”, “conversazione”, “profilo pubblicato”. Never “inquilino affidabile”, “approvato”, “garantito”, “migliore candidato” or a percentage for people. Explain data audience before publication. Errors explain how to recover. Verification language names exactly what was checked, by whom, when and what it does not prove.

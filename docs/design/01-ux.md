# UX architecture — Phase 8

Public navigation: home → how it works / safeguards → create account or login. Account routes: overview, search profile, properties, discover (landlords), invitations, conversations, settings/safety. Staff routes: reports, users (admin), aggregate activity. A both-role account uses the same navigation without separate identities.

| Stage | User sees | Action / recovery |
|---|---|---|
| New tenant | Private draft and explanation of discovery fields | Complete required preferences; preview; publish deliberately |
| New landlord | No property yet, clear create action | Describe current vacancy and attest permission; publish |
| Discovery | Only approved pseudonymous fields + criterion explanations | Choose own published property; no results → adjust property facts or return later, no invented profiles |
| Invitation | Property summary, coarse location, terms and pending status | Accept/decline; accept opens chat only; no financial file disclosure |
| Changed profile/property | Invalid pending invitation cannot be accepted | Explain revalidation and allow decline/withdraw; edits never silently preserve old eligibility |
| Conversation | Other party's chosen display name, property and messages | Send, close, block, report; no email/address reveal by default |
| Verification | Email-confirmation scope and unavailable provider notice | No clickable fake identity/income verification; no unverified badge in discovery |
| Account control | Publication state, own export, deletion and block management | Confirm destructive deletion in UI, revoke sessions, explain conversation removal |
| Staff report | Reporter identity, reason, target invitation and selected message only; disclose this before submission + auditable actions | Resolve with reason; no general chat browser |

Discovery is authenticated, requires a current owned property and limits batches to24. Profiles are never public/indexable. Staff cannot browse private drafts by default. A report grants narrow case context, not blanket staff access to messages. Mutual match authorises conversation and display name, not documents/contact disclosure.

Publication copy explicitly lists city, budget, start, duration and occupants; excludes email, name and optional checks. Pausing removes discovery/new-invite access immediately and cancels pending invitations; accepted conversations remain until closed/block. Any profile/property edit cancels pending invitations, including compatible changes. The local version does not allow another invitation for a terminal property/tenant pair. Stable per-property ordering uses an opaque-ID-derived tie-break, never perceived tenant quality; its exposure fairness is unvalidated and must be studied before pilot scale.

Keyboard: native labels, fieldsets, visible focus, skip link, meaningful links/buttons; route changes announce headings/focus; errors have alert semantics; no colour-only statuses. Mobile: stacked cards and wrapping tabs, no clipped table as primary workflow. Empty/loading/error/expired/blocked states belong to each route. No unsolicited document upload.

Before invitation send/accept, disclose that an accepted match reveals each party's chosen display name (a pseudonym is allowed), property summary and chat; it never automatically releases email or documents. Tenants see the same approved compatibility comparisons inside their own invitation and can correct preferences. Suspended users receive an accessible status and case code; the synthetic local build describes operator review through the local administrative workflow, with an actual staffed contact required before release.

This version represents one search episode per account/property and permanently remembers terminal invitation pairs. It does not implement live research cohort KPIs. Standalone screening utility (research08 O7) is deferred. Empty discovery offers correction of genuinely wrong facts or a return later; it must not encourage fabricating criteria. No-invitation and already-invited cases are explained without revealing private demand counts.
